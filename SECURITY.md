# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
|  1.0   |      ❗🚫     |
|  2.0   |       🚫      |
|  2.1   |   🚫⚠️❌❗   |
|  2.2   |       ✅      |
|  3.0   |       ✅      |
|  4.0   |       ✅      |
| 4.0.1  |       ✅      |
|  5.0   |       ✅      |
|  5.1   |       ✅      |

*❗ means, that, that version is not recommended to use.
❌ means, that, that version is unusuable. 
⚠️ means, that this version, is a Beta/Pre-Release.
✅ means it's usuable, and supported.
And 🚫 means, that, that version has no support at the moment.*

## Supported Windows Versions

| Version | Supported          |
| ------- | ------------------ |
|  Windows 11   |      ✅     |
|  Windows 10   |      ✅     |
|  Windows 8/8.1|      ❗     |
|  Windows 7    |      ❗     |
|  Windows Vista and older   |       ❌      |

*❌ means, that you can't use Delete Temporary Files on that version of Windows. 
❗ means, that Delete Temporary files is only particcally working on that version of Windows.
⚠️ means, that the developers are testing Delete Temporary Files on that version of Windows.
✅ means it's usuable, and supported.*
