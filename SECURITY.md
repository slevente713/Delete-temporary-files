# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
|  1.0   |      ❗🚫     |
|  2.0   |       🚫      |
|  2.1   |   🚫⚠️❌❗   |
|  2.2   |       ✅      |
|  3.0   |       ✅      |
|  4.0   |       ✅      |
| 4.0.1  |       ✅      |
|  5.0   |       ✅      |

*❗ means, that, that version is not recommended to use.
❌ means, that, that version is unusuable. 
⚠️ means, that this version, is a Beta/Pre-Release.
✅ means it's usuable, and supported.
And 🚫 means, that, that version has no support at the moment.*

## Reporting a Vulnerability
If you found Security vulnerabilities, or bugs, please report it to me, via the *Issues* menu, or [via E-Mail](mailto:slevente001@proton.me). (slevente001@proton.me)
